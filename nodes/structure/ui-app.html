Framework-Fehler ab der gewählten Stufe werden redigiert per SSE an alle verbundenen Browser gesendet.

  • aus — keine Weiterleitung (Standard, sicher)
  • debug — alle Meldungen einschließlich Debug
  • info — Info, Warnungen und Fehler
  • warn — Warnungen und Fehler
  • error — nur Fehler

Sicherheitshinweis: Aktivieren Sie die Weiterleitung nur in vertrauenswürdigen Umgebungen. Trotz Redaktionierung können Fehlermeldungen interne Informationen enthalten.
